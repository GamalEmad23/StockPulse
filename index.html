الدليل الشامل لبناء لوحة التحكم في Excel

يشرح هذا القسم بالتفصيل كيفية نقل هذه التجربة التفاعلية وإعداده بالكامل على برنامج Microsoft Excel عبر هيكلية احترافية مقسمة إلى 3 أوراق عمل (Sheets).

1. Transactions (صفحة البيانات)

تُسجل فيها كل صفقات البيع والشراء والعمولات بشكل منهجي.

  • تحويل البيانات لـ Table بالضغط على Ctrl + T.
  • إضافة صيغة الربح/الخسارة التلقائية.
  • إنشاء قوائم منسدلة لحالة الصفقة (مفتوحة/مغلقة).

2. Pivot_Engine (المحرك)

صفحة خفية تحتوي على الجداول المحورية لمعالجة البيانات وتجهيز الرسومات.

  • جدول 1: توزيع القيمة السوقية لكل سهم.
  • جدول 2: منحنى الأرباح التراكمية شهرياً.
  • جدول 3: ترتيب الأسهم الرابحة والخاسرة.

3. Dashboard (اللوحة)

الواجهة البصرية النهائية التي يعتمد عليها المستثمر لاتخاذ القرارات.

  • ربط بطاقات الـ KPIs بخلايا المحرك.
  • إدراج Pivot Charts متجاوبة.
  • إضافة Slicers وتفعيل Report Connections.
